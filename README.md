## Об игре

Молодой инженер приезжает на заброшенную станцию в степи под Актобе. Фермерам нужен метеоспутник, чтобы заранее знать о засухе и бурях. Каждый вечер прилетает грузовой дрон и забирает слитки для ракеты. Через 5 дней ракета должна взлететь.

Сначала всё делается руками: копать руду, поливать грядки, плавить слитки в костре. Квоты растут быстрее, чем успевают руки (5, 10, 20, 35, 50 слитков), поэтому игрок строит фабрику: бур, конвейеры, печь, поливалку, сборщик. Ночью игрок спит, а фабрика работает.

Почему автоматизация здесь ядро игры (три вопроса ТЗ):

| Вопрос | Ответ |
|---|---|
| Сломается ли игра без автоматизации? | Да. Руками выходит 8–10 слитков в день, а квота 4-го дня 35. |
| Можно ли улучшать систему после запуска? | Да. Больше буров и печей, перестройка линий, рентген показывает узкие места. |
| Работает ли без постоянного ручного ввода? | Да. Ночью фабрика производит сама, утром отчёт. |

Полный дизайн: [docs/GDD.pdf](docs/GDD.pdf).

## Как играть

| Клавиша | Действие |
|---|---|
| A / D | идти |
| Пробел | прыжок |
| W / S | вверх и вниз по лестнице |
| ЛКМ (держать) | инструмент: копать, поливать, собирать, раздувать костёр |
| ПКМ | поставить машину или посадить зерно |
| Q | повернуть выход машины |
| E | положить в машину, взять из машины или со склада |
| F (держать) | снести машину, ресурсы возвращаются |
| 1–9 | слоты хотбара |
| X | рентген узких мест |
| Z | лечь спать (после 18:00) |
| Esc | пауза и меню |

Цель дня: до 18:00 привезти на склад столько слитков, сколько просит дрон. Каждая несданная квота отнимает одно из трёх «доверий». Когда доверие кончилось, проект закрыт.

## Запуск

**Из исходников.** Нужен [Godot 4.4.1](https://godotengine.org/download/archive/4.4.1-stable/) (стандартная версия, не .NET).

1. Склонировать репозиторий.
2. Открыть `project.godot` в Godot.
3. Нажать F5.

**Готовый билд.** _Заполнить: ссылка на Web-версию и архив для Windows x64 (папка `build/`)._

**Тесты симуляции без графики:**

```
godot --headless --path . res://tests/SimTest.tscn
```

## Технологии

- Godot 4.4.1, GDScript, рендерер Compatibility (WebGL 2).
- Симуляция фабрики отделена от графики: фиксированный тик 0,25 с, не зависит от FPS, запускается без окна в тестах.
- Все числа баланса в JSON (`data/`), в коде чисел нет.
- Схема модулей и интерфейсы: [docs/CONTRACT.md](docs/CONTRACT.md).

```
autoload/   GameState, DayCycle, SaveManager, Audio
sim/        симуляция: сетка, машины, конвейеры, жилы, ферма
player/     игрок и постройка
view/       отрисовка мира по состоянию симуляции
ui/         HUD, меню, отчёт, обучение
world/      карта
data/       числа баланса и тексты
tests/      проверка симуляции без графики
assets/     спрайты, звук, шрифты
build/      готовые сборки
docs/       GDD, контракт, план команды
```
