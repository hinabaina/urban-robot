## О чём игра

Фабрика и ферма с видом сбоку. Молодой инженер на заброшенной станции в степи под Актобе за 5 игровых дней превращает ручной труд (копать руду, поливать грядки, плавить в костре) в автоматическую фабрику и запускает метеоспутник.

- **Тема AUTOMATE IT!** Игрок автоматизирует сам себя: бур вместо кирки, печь вместо костра, конвейер вместо беготни, поливалка и сборщик вместо лейки.
- **Победа:** сдать квоту пятого дня (всего 120 слитков), сохранив хотя бы одно из трёх «доверий». **Поражение:** доверие упало до нуля.
- **Счёт:** до трёх звёзд — запуск, ни одной сорванной квоты, автоматизация не ниже 80% (доля слитков, которых не касались руки).

Три вопроса теста на автоматизацию из ТЗ:

| Вопрос | Ответ |
|---|---|
| Сломается ли игра без автоматизации? | Да. Руками выходит 8–10 слитков в день, а квоты растут: 5, 10, 20, 35, 50. |
| Можно ли улучшать систему после запуска? | Да. Больше буров и печей, перестройка линий, рентген (X) показывает узкие места. |
| Работает ли она без ручного ввода? | Да. Ночью игрок спит, фабрика работает, утром — отчёт. |

## Как играть

| Клавиша | Действие |
|---|---|
| A / D | идти |
| Пробел | прыжок |
| W / S | по лестнице вверх и вниз |
| 1–9, колесо мыши | выбрать инструмент или машину |
| ЛКМ (держать) | копать, поливать, собирать урожай, раздувать костёр |
| ПКМ | поставить машину (зажать и тянуть — проложить конвейер), посадить зерно |
| Q | повернуть выход машины |
| E | положить в машину / забрать из неё, сдать слитки на склад |
| F (держать) | снести машину, ресурсы возвращаются |
| X | рентген узких мест |
| Z | лечь спать (после 18:00) |
| Esc | пауза |

Сессия длится 10–12 минут, игровой день — 2 минуты. Перед первой игрой идёт вступительный ролик на 40 секунд с голосом рассказчика: засуха, зачем нужна ракета и почему руками не успеть (пропускается клавишей Esc, Пробел или кнопкой; пересмотреть можно из меню). В первый день работает обучение: подсказка внизу экрана и стрелка на цель.

## Запуск

- **Web (Chrome, Firefox):** https://hinabaina.github.io/urban-robot/ — открыть ссылку и нажать «Новая игра».
- **Windows 10/11 x64:** скачать https://hinabaina.github.io/urban-robot/dala-works-win64.zip, распаковать и запустить `DALA_WORKS.exe`. Установка не нужна.
- Обе сборки делает GitHub Actions из ветки `main`. Как собрать самому: [build/README.md](build/README.md).
- **Из исходников:** открыть папку проекта в Godot **4.7.2-stable** и нажать «Запустить» (F5).

Проверка симуляции без графики (работает на любой системе):

```bash
godot --headless --path . res://tests/SimTest.tscn
```

Ожидаемая последняя строка: `Итог: 176 ок, 0 провалено`.

Автопроверки игры целиком (нужен Linux с `xvfb`):

```bash
tools/b_smoke/shot.sh /tmp/out.png 0.3 checks
```

Ожидаемая последняя строка: `RESULT: ALL PASS`.

## Технологии

- Движок: Godot 4.7.2, язык GDScript, рендерер Compatibility (для Web).
- Данные отдельно от кода: `data/*.json` (квоты, скорости, цены), тексты — `data/translations.csv`.
- Графика и звук создаются скриптами: `tools/art` (Python + Pillow) и `tools/audio` (Python + numpy, ffmpeg).
- Архитектура: симуляция (`sim/`, участник A) не знает о сцене; игрок и часы отдают ей команды, отрисовка и интерфейс читают состояние и слушают сигналы.
- Симуляция считает фиксированными тиками по 0,25 с и не зависит от FPS: ночь на скорости ×20 даёт тот же результат, что и ×1. Порядок тика и обратное давление на конвейерах описаны в `docs/CONTRACT.md`, раздел 7.
- Симуляция проверяется без графики: `tests/SimTest.tscn` собирает фабрики кодом и сверяет числа с балансом GDD.
- ИИ-инструменты: Claude (Anthropic) — помощь с кодом, графикой и звуком; ElevenLabs — голос рассказчика во вступительном ролике.

## Известные баги и ограничения

- «Продолжить» и «Повторить день» ещё не подключены к меню: сохранение в движке готово (`SaveManager`), осталась кнопка.
- Если карманы полны, руда не копается (в GDD лишний предмет лежит на земле 30 секунд).
- Звук и музыка синтезированы кодом и ещё не проверены на слух.
- Казахский перевод — черновик, его нужно вычитать носителю языка (переключается в настройках главного меню).
