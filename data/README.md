# data/ — числа баланса и тексты

Все числа игры лежат здесь, в коде их нет. Стартовые значения взяты из GDD.

| Файл | Владелец | Что внутри |
|---|---|---|
| `machines.json` | A | размер, цена, скорости, рецепты и буферы машин |
| `world.json` | A | длина тика, размер мира, время копания по слоям, запасы жил, колодец, ферма, окно статистики |
| `days.json` | B | часы суток, стартовые карманы и доверие, квоты, подарки дрона, условие третьей звезды |
| `player.json` | B | движение, лимиты карманов, хотбар, времена ручных действий |
| `tutorial.json` | B | шаги обучения |
| `translations.csv` | B | тексты RU / KZ |

Ручки настройки сложности по порядку (GDD «Баланс»): квоты дней 4 и 5 (`days.json`), скорость печи (`machines.json`, `furnace.cycle_seconds`), цена бура в слитках (`machines.json`, `drill.cost`), длительность ночи (`days.json`).

После изменения чисел в `machines.json` или `world.json` запустите `tests/SimTest.tscn`: часть проверок сверяет результат с балансом GDD и покажет, что сдвинулось.
