# data/ — числа баланса

Все числа игры лежат здесь, в коде их нет. Стартовые значения взяты из GDD.

| Файл | Владелец | Что внутри |
|---|---|---|
| `machines.json` | A | размер, цена, день открытия, слот хотбара, скорости и буферы машин |
| `world.json` | A | длина тика, размер мира, слои и время копания, запасы жил, колодец, ферма |
| `days.json` | B | время суток, доверие, карманы, квоты по дням, подарки дрона, события |
| `tutorial.json` | B | шаги обучения (появится на этапе B11) |
| `translations.csv` | B | тексты RU / KZ |

Ручки настройки сложности по порядку (GDD «Баланс»): квоты дней 4 и 5, скорость печи, цена бура в слитках, длительность ночи.
