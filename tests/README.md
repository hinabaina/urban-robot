# tests/ — владелец A

Проверка симуляции без графики.

```
godot --headless --path . res://tests/SimTest.tscn
```

Код возврата 0 и строка «Итог: N ок, 0 провалено» означают, что всё цело. Запускать перед каждым PR.

- `SimTest.gd`: точка входа, контракт, данные, тики.
- `TestBuild.gd`: постановка и снос машин.
- `TestManual.gd`: склад, дрон, костёр, копание, грядки.
- `TestWorld.gd`: маленькие миры, собранные кодом.
- `TestCase.gd`: мини-фреймворк проверок.
