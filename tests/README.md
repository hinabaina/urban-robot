# tests/ — владелец A

Проверка симуляции без графики. Фабрики собираются кодом, время прокручивается тиками, числа сверяются с GDD.

```
godot --headless --path . res://tests/SimTest.tscn
```

Код возврата 0 и строка «Итог: N ок, 0 провалено» означают, что всё цело. Запускать перед каждым PR.

| Файл | Что проверяет |
|---|---|
| `SimTest.gd` | точка входа; методы и сигналы из `docs/CONTRACT.md`; числа GDD в JSON |
| `TestHands.gd` | копание, общий запас жилы и её исчерпание, костёр, склад, дрон |
| `TestLogistics.gd` | конвейер 1 тайл/с, обратное давление, лифт и поворот, слияние по очереди, кольцо |
| `TestFactory.gd` | состояния машин, баланс «1 бур + 1 печь», флаг `by_hand`, ночь x20 = x1, бур на конечной жиле |
| `TestFarm.gd` | рост и полив, новые грядки, поливалка, сборщик |
| `TestSave.gd` | сохранение и загрузка, отказ на чужой версии, запись на диск |
| `TestRealMap.gd` | настоящая карта `world/World.tscn`: 5 жил, 12 грядок, готовые постройки |
| `TestWorld.gd`, `TestCase.gd` | маленькие миры для тестов и мини-фреймворк проверок |
