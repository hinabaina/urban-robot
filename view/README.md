# view/ — владелец B

Отрисовка мира по состоянию симуляции: `WorldView.gd` (тайлы и грядки по сигналам), `MachineView.gd` (машины и их состояния), `ItemSprites.gd` (предметы по `Sim.get_items()`), `XRay.gd` (рентген по `Sim.get_stats()`).

Здесь нет логики: вид только читает `Sim` и слушает его сигналы.
